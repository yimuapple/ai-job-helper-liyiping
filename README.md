# 秋招AI求职助手

一个 Chrome 浏览器插件，帮应届生从"盲投"到"精准投递"，覆盖秋招全流程：岗位分析 → AI定制简历 → 一键填表。

## 核心功能
- 🎯 岗位JD智能分析：AI判断岗位匹配度，建议是否值得投递
- 📄 AI定制简历：根据目标岗位JD自动筛选相关经历，生成定制版简历
- ⚡ 网申一键填表：自动识别招聘网站表单字段，一键填充，支持BOSS直聘、智联、前程无忧、牛客

## 技术栈
- 前端：原生 HTML / CSS / JavaScript（Chrome Extension Manifest V3）
- AI：DeepSeek API
- 数据：chrome.storage.local 本地存储
